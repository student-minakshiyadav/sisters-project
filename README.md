## ⚙️ Installation & Setup

Clone the repository:

bash
git clone https://github.com/student-minakshiyadav/sisters-project.git


Go to project folder:

bash
cd sisters-project


Install dependencies:

bash
npm install


Run the project:

bash
npm run dev
